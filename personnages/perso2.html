🔗 Voir le build sur Evowow

Points : 0 Arcane · 53 Feu · 18 Givre

Build standard Mage Feu PvE. Le givre est pris uniquement pour Winter's Chill (debuff crit sur la cible) — indispensable si personne d'autre ne l'applique dans le groupe.

Talents clés

  • Hot Streak — Deux crits consécutifs → Pyroblast instantané. Cœur du DPS Feu.
  • Living Bomb — DoT qui explose à la fin. Maintenir en permanence sur la cible.
  • Pyromaniac — +15% dégâts si 3+ cibles brûlent. Boost énorme sur multi-cibles.
  • Combustion — Chaque crit donne un stack de +10% crit feu. CD offensif majeur.
  • Improved Scorch — Applique un debuff -15% résistance feu sur la cible. À maintenir.

Glyphes

  • Glyphe de Boule de feu — +5% crit sur Fireball. Glyphe n°1 obligatoire.
  • Glyphe de Bombe vivante — +3% crit sur Living Bomb.
  • Glyphe de Combustion — +10s de durée sur Combustion.
  • Glyphe mineur — Slow Fall — Qualité de vie, plus besoin de reagent.

Priorités de base

1. Living Bomb — Maintenir en permanence sur la cible (DoT + explosion)
2. Pyroblast! — Dès que Hot Streak proc (instant) — priorité absolue
3. Fireball — Sort principal, spam en permanence
4. Fire Blast — Filler instant entre les casts / pour déclencher Hot Streak
5. Scorch — En déplacement uniquement, maintenir le debuff Improved Scorch

Cooldowns offensifs

CD Combustion — Utiliser sur pull, chaque crit = +10% crit. Stack vite avec Fireball.
CD Mirror Image — Utiliser tôt, génère de la menace sur les copies (pas sur vous).
CD Presence of Mind — Si pris : prochain sort instantané — à combiner avec Pyroblast pour burst.
🔥 Fenêtre de burst idéale : Combustion → Pyroblast! (Hot Streak) → Fire Blast → Fireball. Le but est d'enchaîner les crits pour maintenir Combustion et les procs Hot Streak.

Multi-cibles (AoE)

1. Living Bomb — Sur chaque cible si possible (max 3 en WotLK)
2. Flamestrike — AoE au sol sur les packs
3. Dragon's Breath — Cône de feu devant vous, bon burst AoE
4. Blast Wave — AoE circulaire autour de vous
