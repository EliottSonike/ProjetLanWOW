Build standard Chasseur Précision PvE pour ICC. Le cœur tourne autour de Tir de Chimère et Tir Constant amélioré. Les 7 points en Bête donnent Suivi amélioré (+5% dégâts). Les 7 points en Survie apportent Coups létaux (+5% crit).

Talents clés

  • Tir de Chimère — Sort signature. Refresh le Venin du Serpent automatiquement + gros dégâts. CD : 10s.
  • Tir Constant amélioré — Après 2 Tirs Constants, le prochain Tir Visé/Chimère/Arcane est 20% plus puissant.
  • Maître Tireur — Réduit le coût en focus de Tir Visé. Permet de spam plus de sorts instants.
  • Flèche Sauvage — Passif : 20% de chance de tir bonus gratuit après chaque Tir Constant.
  • Tir Silencieux — Interrupt ranged à 24m. Indispensable pour les casters en raid.

Glyphes

  • Glyphe de Tir Constant — +10% dégâts quand Venin du Serpent est actif.
  • Glyphe de Tir de Chimère — Réduit le CD de 1s (9s au lieu de 10s).
  • Glyphe de Tir Mortel — Si Tir Mortel ne tue pas, le CD est reset.
  • Glyphe mineur — Revivification — Réduit le coût en mana du rez en combat.

Pre Flèche de Traqueur — 2s avant le pull si possible
1. Venin du Serpent — Appliquer immédiatement (DoT principal)
2. Tir de Chimère — Refresh automatique Venin + gros dégâts
3. Tir Visé — Si buff Tir Constant amélioré actif
4. Tir Rapide + Trinkets — Activer les CDs offensifs sur le pull

Rotation en combat (Priorité)

1. Tir Mortel — Si la cible est <20% — priorité absolue
2. Tir de Chimère — Sur cooldown (9-10s), votre sort le plus puissant
3. Tir Visé — Si buff Tir Constant amélioré actif (2 Steady Shots consécutifs)
4. Tir Arcane — Filler instant si Chimère et Visé sont en CD
5. Tir Constant — Spam de base, génère le buff +20% (x2 = proc Tir Visé amélioré)
🏹 Règle d'or : Chimère passe TOUJOURS avant Tir Visé. Venin du Serpent est automatiquement refreshé par Chimère — ne jamais le ré-appliquer manuellement.
