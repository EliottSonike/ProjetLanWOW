Points : 0 Sacré · 53 Protection · 18 Vindicte

Build standard Paladin Tank PvE. Les points en Vindicte donnent accès à Seal of Command et améliorent la génération de menace. Priorité : atteindre le cap de défense avant tout.

Talents clés

  • Righteous Fury — Augmente la menace générée par vos sorts sacrés de 90%. À activer en permanence.
  • Shield of Righteousness — Sort de dégâts basé sur le Block Value. Votre outil de menace le plus puissant.
  • Hammer of the Righteous — AoE à 3 cibles, clé pour maintenir la menace sur les packs.
  • Divine Guardian — Réduit les dégâts subis par le raid de 30% pendant 6s. CD de raid précieux.
  • Judgements of the Just — Applique un debuff -20% vitesse d'attaque sur l'ennemi. Réduction de dégâts passive.

Glyphes

  • Glyphe de Bouclier de la Justice — +5% dégâts sur SoR.
  • Glyphe de Jugement — +10% dégâts sur Judgment.
  • Glyphe de Consécration — +2s de durée sur Consecration.
  • Glyphe mineur — Sense Undead — Utile dans Naxxramas contre les morts-vivants.

Le système 969

🛡️ La rotation Prot Paladin repose sur le système 969 : alterner des sorts à 9s de CD et des sorts à 6s de CD pour ne jamais avoir de GCD vide.
9s Judgment — CD 9s. Applique debuff, génère menace.
6s Shield of Righteousness — CD 6s. Dégâts basés sur Block Value. Menace élevée.
9s Holy Shield — CD 9s. Maintenir actif — augmente Block Chance de 30%.
6s Hammer of the Righteous — CD 6s. AoE 3 cibles. Essentiel pour les packs.
9s Consecration — CD 9s. AoE au sol, menace passive sur toutes les cibles proches.
15s Avenger's Shield — CD 15s. Hors rotation 969 — à caser entre les GCDs. Pull + silence 3 cibles.

CDs défensifs

CD Divine Protection — -50% tous dégâts pendant 10s. CD 1 min. À utiliser sur les gros pics de dégâts.
CD Lay on Hands — Soin total sur vous-même ou un allié. CD long — réserver aux urgences.
CD Divine Guardian — -30% dégâts sur tout le raid pendant 6s. CD de raid précieux — communiquez avec les healers.
